## 📝 Descripción del Proyecto

Este repositorio contiene la recopilación de prácticas, ejercicios y proyectos desarrollados durante la asignatura de **Desarrollo de Aplicaciones Móviles Multiplataforma**. 

El objetivo principal es aprender y dominar el ecosistema de **Flutter** y **Dart**, abordando desde los conceptos fundamentales del lenguaje, el manejo de estado (`StatefulWidget` y `StatelessWidget`), hasta el consumo de APIs externas, maquetación de interfaces interactivas y control de versiones con **Git** y **GitHub**.
